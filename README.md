# Cercle unitaire trigonométrique

Figures dynamiques du cercle unitaire, pour le cours « La trigonométrie au service de l'électricien » de la série « Du calcul au chantier ».

- `index.html` : l'angle arrêté φ, en degrés.
- `radians.html` : l'angle ωt qui varie, en radians.

Quand l'angle varie, c'est ωt ; quand il est arrêté, c'est φ.
